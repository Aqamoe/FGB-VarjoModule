# 真机验收清单

> 当前状态：**未验证**（社区未验证实现）。下列任一项完成后，请在 issue 里附设备与版本信息。

## 环境

| 项 | 值 |
|---|---|
| 头显 | Varjo XR-3 / XR-4 / VR-3 / VR-4 / Aero（记录型号，需带眼动追踪） |
| 运行时 | Varjo Base（记录版本号；睁眼度/瞳孔还需 **Varjo Base Pro** 授权） |
| 系统 | Windows 10 / 11 x64 |
| 宿主 | FaceGaze Bridge（记录版本号） |
| 其它 | 关闭 VRCFaceTracking，避免与其 Varjo 模块冲突 |

## 步骤

- [ ] Varjo Base「设置 → 眼动」启用眼动追踪并完成校准
- [ ] 佩戴头显，确认头显图像正常
- [ ] FGB「模块库 → 原生模块」安装 `varjo-0.1.0.zip`
- [ ] 「模块」页把 **Varjo Eye Tracking** 设为启动，角色给 `eyes`（需要注视通道时给 `gaze`），重启引擎
- [ ] 模块卡片显示活跃；摘下头显 2 秒内卡片出现「已 N 秒没有有效眼动数据」

## 观察项

- [ ] 注视方向：看左/右/上/下 → `gaze_dir` 各分量符号符合右手系（X 右、Y 上、-Z 前）
- [ ] 合并注视与辐辏：看近/看远 → `vergence_distance_m` 在 (0,2] 内变化
- [ ] 睁眼度：眨眼 → `openness` 掉到接近 0，左右眼独立
- [ ] 瞳孔：有 Pro 授权时 `pupil_diameter_mm` 在 2..6mm 量级；无授权时属性位不置、日志提示一次
- [ ] 校准中（Adjust）：注视不更新但模块不报错刷屏
- [ ] 未佩戴（status=0）：注视停更、卡片给出提示；重新佩戴后自动恢复
- [ ] 未安装 Varjo Base 直接启动：卡片报「请先安装 Varjo Base」，宿主不崩溃

## 单位/极化重点（最容易错）

- Varjo 原始方向是**左手系 +Z 前**；本模块翻 Z 输出 **右手系 -Z 前**。
  如果头像/可视化里左右或上下反了，记录型号与 Base 版本并提 issue。
- 注视射线相对头姿：转头时世界注视点应基本不动（若宿主做了头姿补偿）。
